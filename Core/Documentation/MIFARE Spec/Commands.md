| Command    | Hex    | Purpose                  |
| ---------- | ------ | ------------------------ |
| REQA       | `0x26` | Ask if a card exists     |
| WUPA       | `0x52` | Wake card                |
| SELECT     | `0x93` | Select card by UID       |
| AUTH Key A | `0x60` | Authenticate using Key A |
| AUTH Key B | `0x61` | Authenticate using Key B |
| READ       | `0x30` | Read a block             |
| WRITE      | `0xA0` | Write a block            |
| HALT       | `0x50` | Stop communication       |
